What it does

One core, three durable layers.

The deterministic core handles state, memory and coordination. The model layer is optional and always outside the storage path.

01

Event-sourced state

Append-only JSONL, SHA-256 content fingerprints and deterministic replay. A double-send is a no-op, not a duplicate. State is rebuilt from the log, never patched in place.

02

Four-tier memory

Working observations, episodic summaries, semantic facts and procedural workflows in SQLite. Hybrid FTS5 recall, substring fallback and Ebbinghaus decay keep the useful facts close.

03

Coordination without a server

TTL leases keep one task with one agent. Signals carry async mail and threads. The action DAG auto-unblocks dependents when their requirements are complete.

Memory model

Built to remember — and to forget.

Four tiers, explicit scopes and a retrieval path that fails closed. Memory is plaintext; privacy is a read-time control, not an encryption claim.

Four tiers, one recall path

Each tier has a different retention rule. Recall draws from all of them and strengthens what it touches.

Tier Table Purpose
Working observations Raw inbound events, bounded per session.
Episodic summaries Session summaries: what happened.
Semantic memories Durable facts with confidence and decay.
Procedural memories Reusable workflows with triggers.
01

Scopes and sensitivity

Records carry a sensitivity label validated against a fixed set. recall and profile return only public and internal by default. An unknown label raises; it is never silently downgraded.

02

Hybrid recall

FTS5 BM25 is the primary match. A substring path covers CJK and camelCase. Strength and Ebbinghaus decay rank what survives; access strengthens, time fades.

03

Evidence, not vibes

The event log is append-only and replayable. Idempotency is a SHA-256 content fingerprint. A suppressed match is filtered before it can strengthen a counter someone else can read.

04

Fail-closed by default

An empty sensitivity set returns nothing. A missing execution adapter returns unavailable. A missing key returns not_run. The default is never assume it worked.

05

Forgetting is measured

forget.py covers eight stores, hardens SQLite, scans raw bytes and emits a receipt. Cryptographic erasure is reported only when cells were actually sealed.

06

Plaintext storage

Memory is not encrypted by default. Sensitive bytes need CellCipher with a key stored outside the data directory, or full-disk encryption. Access control is not encryption.

Trust boundary

The boundary is the feature.

The core decides, records and reports. It does not pretend to be an operating-system sandbox.

01

Honesty boundary

Local gates are executed and evidence-backed. Native and external lanes publish not_run or pending when the host or credentials are missing. No superiority or native-parity claim is made without matching evidence.

02

Capability decisions

Three-valued authorization, explicit ACL grants, HMAC capability tokens, logical private scopes and an auditable decision trail. Deny is a first-class result.

03

No in-process model code

The deterministic core is stdlib-only and never executes model-generated Python in-process. The LLM is a pluggable callback, not a dependency.

04

OS sandbox not included

This is not a VM, container or hardened remote executor. The execution ladder returns unavailable until a real adapter is configured.

05

Plaintext by default

Storage is not encrypted by default. Sensitive bytes need CellCipher with an external key store, or full-disk encryption. Access control is not encryption.

06

Stable status vocabulary

Status words stay English by contract, so evidence remains machine-readable across hosts and reports.

passedfailedblockednot_runnot_startedunknown

not_run is an honest statement about a missing host or key, never a failure disguised as success.

Not claimed

  • No production-ready or secure-sandbox claim.
  • No beats-X claim without external A/B evidence.
  • No native parity claim without a matching host.
