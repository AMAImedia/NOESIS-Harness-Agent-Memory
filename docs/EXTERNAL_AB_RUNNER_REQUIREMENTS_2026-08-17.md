# External A/B Runner Requirements

External baseline execution is an optional, approval-gated evidence lane for Hermes, OpenCode, and DeepSeek Harness. A valid run requires an exact immutable revision, task-manifest digest, protocol fingerprint, disposable workspace, seed digest when required by the manifest, credential isolation, deny-by-default network policy, capability-aware preflight, signed receipt, and reproducible result artifact.

The pinned orchestrator validates the manifest before planning a pinned lane. Floating revisions, missing seed digests, invalid workspace/budget policy, missing executables and unavailable capabilities remain `not_run` or `blocked`. Approval uses `noesis.external-approval.v1`: an HMAC receipt binds the exact command digest, argv-derived plan, workspace, revision, protocol fingerprint and task-manifest digest, has a bounded expiry, and must be consumed through a persistent receipt store exactly once. Missing, expired, mutated or replayed approval receipts remain denied; approval must never be coerced into `passed`, `failed`, or a comparative ranking.
