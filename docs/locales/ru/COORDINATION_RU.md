# Strict one-agent-one-lease mode

`Leases(..., one_lease_per_holder=True)` — режим, при котором у одного агента-держателя одновременно может быть только одна активная аренда задачи. Повторная попытка захватить задачу тем же держателем завершается отказом с `reason: holder_lease_active`; повторный захват той же задачи остаётся идемпотентным. Режим по умолчанию остаётся устаревшим task-exclusive (для совместимости), поэтому координаторам, которым нужен строгий один агент на цикл делегирования, нужно явно включить strict-режим. Общие рабочие пространства и общие capabilities по-прежнему запрещены в `SafeParallelExecutor`; финальная интеграция остаётся за координатором.
